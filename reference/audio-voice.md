# Звук и голос

Пути `scripts/…` — относительно папки скилла.

## Музыка и эффекты — `audio_bed.py`

```bash
python3 scripts/audio_bed.py --timeline timeline.json --out mix.wav --stems stems --key Am --style drive
```

- Читает из `timeline.json` темп (`bpm`), длину (`end`), тональность (`key`), секции музыки (`music`) и звуковые события (`cues`).
- Секции: `intro` — мягкий вход, `main` — основная часть, `gap` — тишина музыки перед главным ударом, `outro` — финальный аккорд и хвост. Секций нет — вся длина считается `main`.
- События `cues`:

  | type | когда звучит |
  |---|---|
  | `hit`, `boom`, `click` | атака ровно в `t` |
  | `tick` | серия из `n` щелчков с шагом `step`, начиная с `t` |
  | `whoosh` | пик в середине `dur` |
  | `riser`, `swell` | нарастают и заканчиваются в `t + dur` |

- `--style drive` — барабаны на каждую долю, `calm` — спокойнее, без бочки на каждую долю.
- Выход: `mix.wav` (48 кГц, 24 бит, длина ровно по `end`), стемы `stems/{drums,bass,music,sfx}.wav` для пересборки под голос, отчёт `audio_report.txt` — громкость, пик, отклонение атак от cues в миллисекундах.
- Один и тот же `--seed` даёт один и тот же файл.

Музыку и эффекты можно отдать субагенту параллельно с картинкой. Задание — темп, тональность, секции и cues из `timeline.json`. Критерии готовности: длина ровно в сэмплах, −14 LUFS, атаки не дальше 15 мс от cues, тишина музыки перед главным ударом.

Готовый трек вместо синтеза — только с подтверждённой лицензией на использование в ролике.

## Голос

- **Платный TTS — сначала образцы.** Одна фраза несколькими голосами → выбор пользователя → полный прогон. Не генерируй весь текст до выбора.
- Темп дикторов обычно выше, чем кажется по тексту: мерь длительность по готовому дублю, не прикидывай.
- Пауза внутри дубля: у части TTS-моделей точки и многоточия между отдельными словами паузы не дают — «От. Эскиза. До. Монтажа.» читается слитно (так ведёт себя, например, Gemini TTS). Паузу даёт граница фраз из нескольких слов (0,4–0,6 с) или склейка из разных дублей.
- Проверяй произношение распознаванием кусками по 2–3 секунды: на целом файле модель путает окончания. Короткую фразу распознавай вместе с соседней: одну «От эскиза» маленькая модель Whisper слышит как «А ты с Киза?». На слабой машине распознавание не запускай одновременно с рендером — оба упираются в память.

## Сведение — `vo_mix.py`

```bash
python3 scripts/vo_mix.py vo_plan.json
python3 scripts/vo_mix.py vo_plan.json --dry-run   # только проверить план: окна фраз и нужен ли atempo
```

План — JSON, пути в нём относительно файла плана:

```json
{
  "timeline": "timeline.json",
  "bed": {"stems": "stems", "music": ["drums", "bass", "music"], "sfx": ["sfx"]},
  "phrases": [
    {"t": 0.5, "take": "vo/take1.mp3", "span": [0.12, 1.40], "text": "Ролик из веб-страницы"},
    {"t": 2.0, "take": "vo/take2.mp3", "span": [0.30, 1.10], "text": "3D без видеокарты"}
  ],
  "voice_hp_hz": 90,
  "duck_db": -7,
  "duck_sfx_db": -3,
  "voice_over_bed_db": 9,
  "max_tempo": 1.12,
  "out": "vo_mix.wav",
  "lufs": -14
}
```

- `t` — где начинается голос фразы, `span` — отрезок дубля в секундах. Фразы можно брать из разных дублей.
- Фраза не влезает до следующей — ускоряется `atempo` без смены тона, но не больше `max_tempo`. Нужно больше — скрипт остановится с подсказкой: сократи фразу или раздвинь время (`remap.py`).
- Ставь фразу ударным слогом на долю.
- Музыка под голосом приседает на `duck_db` (−7 дБ; в стоп-тайме хватает −3), эффекты — на `duck_sfx_db`. Голос стоит на `voice_over_bed_db` (+9 дБ) над присевшей подложкой.
- Выход: `vo_mix.wav`, отдельно голос `vo_voice.wav` и отчёт `vo_report.txt` по фразам: время, длительность, темп, превышение голоса над подложкой.

## Мастер

- Итоговая громкость — −14 LUFS, true peak не выше −1 dBTP. Оба скрипта мастерят сами.
- AAC добавляет к пику до +0,5 дБ: wav с пиком −1,2 dBTP после кодирования дал −0,8. Поэтому `finalize.sh` ставит `alimiter=limit=0.79:level=false` (−2 dBFS) прямо перед кодером. Без `level=false` лимитер поднимает уровень и может клиповать.
- Проверка готового файла:
  ```bash
  ffmpeg -hide_banner -nostats -i out/promo.mp4 -af ebur128=peak=true -f null - 2>&1 | grep -E ' I:|Peak:'
  ```
