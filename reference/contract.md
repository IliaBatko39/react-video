# Контракт страницы и формат timeline.json

Пути `scripts/…` и `templates/…` — относительно папки скилла.

## Что страница обязана дать рендеру

| Имя | Что это |
|---|---|
| `window.T` | Таймлайн — объект из `timeline.json`. Минимум `end` — длительность в секундах. `fps`, `width`, `height` из него — значения по умолчанию для рендера. |
| `window.render(t, gt)` | Рисует кадр момента `t` (секунды). Чистая функция `t`. `gt` — время выходного кадра: при перекарте времени отличается от `t`, им сидируют зерно. Может вернуть Promise — рендер его дождётся. |
| `window.sceneReady` | `true`, когда загружены шрифты (с кириллицей), картинки и 3D. Рендер ждёт этот флаг и падает с понятной ошибкой при ошибках на странице и незагруженных картинках. |
| `window.layoutBoxes(t)` | Необязательно. Рамки текста, нарисованного на canvas, для `layout_check.py`: `[{name, x0, y0, x1, y1, words}]`. |

Страницу по умолчанию ищут как `index.html` в корне папки `--dir` (другое имя — `--page`). Отдаёт её локальный HTTP-сервер `render.py`, поэтому модули, `fetch` и шрифты работают как на обычном сайте.

Разметка для `layout_check.py`:
- `data-check` — элемент должен целиком лежать в безопасной зоне, когда виден;
- `data-read` — текст, который зритель должен успеть прочитать; слова считаются по сцене.

## timeline.json

```json
{
  "fps": 30, "width": 1080, "height": 1920,
  "end": 8.0,
  "bpm": 120, "key": "Am",
  "scenes": [
    {"id": "title", "t0": 0.0, "t1": 2.0},
    {"id": "three", "t0": 2.0, "t1": 4.5}
  ],
  "music": {"intro": [0.0, 2.0], "main": [2.0, 6.0], "gap": [5.75, 6.0], "outro": [6.0, 8.0]},
  "cues": [
    {"t": 1.6, "type": "whoosh", "dur": 0.4},
    {"t": 2.0, "type": "hit"},
    {"t": 3.0, "type": "tick", "n": 4, "step": 0.25},
    {"t": 5.0, "type": "riser", "dur": 1.0},
    {"t": 6.0, "type": "boom"}
  ]
}
```

| Поле | Кто читает | Смысл |
|---|---|---|
| `end` | все | длительность, с |
| `fps`, `width`, `height` | `render.py` | по умолчанию 30 и 1080×1920 |
| `scenes` | `layout_check.py`, `sheet.py`, `remap.py`, страница | сцены: `id`, начало `t0`, конец `t1` |
| `bpm`, `key` | `audio_bed.py` | темп и тональность (`Am`, `C`, `F#m`…) |
| `music` | `audio_bed.py`, `remap.py` | секции музыки: `intro`, `main`, `gap`, `outro` |
| `cues` | `audio_bed.py`, `remap.py`, страница | звуковые события: `hit`, `boom`, `whoosh`, `riser`, `tick`, `click`, `swell`; у части — `dur`, у серии `tick` — `n` и `step` |
| `remap` | `render.py --remap` | точки перекарты `[[новое, старое], …]`; пишет `remap.py`, руками не править |

Свои поля добавлять можно: скрипты читают только свои.

## Перекарта времени

```bash
python3 scripts/remap.py timeline.json remap.json -o timeline_long.json
python3 scripts/remap.py timeline.json --points "0:0,2:2,3.15:3,25:19.5" -o timeline_long.json
```

`remap.json` — `{"remap": [[новое, старое], …]}`, обе координаты строго растут. Скрипт пишет новый `end`, сами точки `remap`, пересчитывает `cues` (время, длительность, шаг серии), `scenes` и секции `music`. Потом `render.py … --remap timeline_long.json` переводит время каждого кадра в старое кусочно-линейно и вызывает `render(старое, новое)`.
