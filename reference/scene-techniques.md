# Приёмы сцены

Пути `scripts/…` и `templates/…` — относительно папки скилла.

## Время

- Всё, что движется, — функция `t`. Изинги, `hash`, `rng` с зерном, `frameOf`, затухающая тряска — в `templates/html/js/util.js`.
- Зерно и тряску сидируй номером кадра `round(gt · fps)`. Тогда подкадры размытия движения видят одно и то же зерно и не «мылят» его. При перекарте времени зерно веди временем выхода `gt`: иначе в удержаниях оно замирает.
- CSS-анимации, переходы и всё, что работает через Web Animations API: поставь на паузу и выставь время.
  ```js
  for (const a of document.getAnimations()) { a.pause(); a.currentTime = t * 1000; }
  ```
  Пример — сцена с CSS в `templates/html/`.
- React: `window.render = t => flushSync(() => root.render(<Video t={t} />))`. Без `flushSync` снимок может уйти раньше, чем React обновит DOM. Пример — `templates/react/src/main.jsx`.
- Картинки, которые меняются по ходу ролика, загрузи и раскодируй (`img.decode()`) до `sceneReady`. Иначе первый кадр с ними уйдёт пустым.

## Локальный HTTP вместо file://

ES-модули и `fetch` со страницы, открытой через `file://`, браузер не грузит. `render.py` сам поднимает локальный HTTP-сервер на папке `--dir`, поэтому `timeline.json`, модули и шрифты грузятся обычным `fetch` и `import`.

## 3D без видеокарты

- WebGL на сервере без GPU работает через SwiftShader. `render.py` запускает Chromium с флагами `--use-angle=swiftshader --enable-unsafe-swiftshader --ignore-gpu-blocklist`; с `--gpu` — без них.
- У рендерера three.js — `preserveDrawingBuffer: true`, как в шаблоне.
- Сцена с тенями отрисовывается за миллисекунды, упор — в сам снимок (0,2–0,3 с на кадр).
- Шаблон подключает three.js с CDN по точной версии через `importmap`. Для офлайн-рендера скачай `three.module.js` и `three.core.js` той же версии (папка `build` пакета three) в проект и поправь `importmap`.
- SVGLoader из three.js не читает CSS-классы из `<style>` — так экспортирует CorelDRAW. Пути выбирай по порядку или по габаритам, цвета бери из своего разбора `<style>`.

## Шрифты

- woff2 с кириллицей и латиницей — в папке проекта, со своим `fonts.css`. Пути в `url()` — относительно самого css (`url(unbounded-900-cyrillic.woff2)`), иначе 404.
- Перед первым кадром загрузи каждое начертание с кириллицей вторым аргументом:
  ```js
  await document.fonts.load("900 100px 'Unbounded'", 'АБВГДЕЁЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯ');
  await document.fonts.ready;
  ```
  Иначе по `unicode-range` подтянется только латиница, и первые кадры уйдут системным шрифтом.
- Большинство шрифтов Google Fonts — под лицензией SIL OFL: их можно класть в проект и в ролик. Лицензию семейства проверь на его странице, файл лицензии держи рядом со шрифтом.

## Контурный текст

Вариативные шрифты (Unbounded, Manrope и другие) собирают глифы из перекрывающихся частей. Поэтому `strokeText` показывает линии внутри букв. Решение — `templates/html/js/outline.js`: штрих двойной толщины рисуется на отдельном холсте, заливка тех же букв вырезается через `destination-out`. Проверяй вырезкой 1:1: на уменьшенном листе кадров линии не видны.

## Ассеты с сайта

Логотип, карта, фото «как на сайте» — это то, что видит посетитель на живой странице. Найди блок на странице и посмотри, откуда он берёт картинку: бывает inline-SVG прямо в `index.html`, а файл с подходящим именем в `img/` давно устарел. Файл, на который ничто не ссылается (`grep` пуст), не бери.

## Что тормозит при программной отрисовке

Без видеокарты `filter: blur`, `drop-shadow` и `mix-blend-mode` на весь кадр стоят до 8 секунд на кадр. Замены, которые выглядят так же, но стоят около 0,25 с на кадр:
- свечение — `radial-gradient` без blur;
- тень — `box-shadow`;
- зерно — готовая текстура обычным наложением или canvas с шумом по зерну кадра.
